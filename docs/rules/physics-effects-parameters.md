更新：2026-10-26。P01–P10、F01–F10、V01–V03 已由用户整组采用，见[确认清单](../physics-effects-confirmation.md)。本轮补充的是数值资料与实验起点，尚未实现物理/药效处理器，也未进行 Hypixel 线上测试。

完整的 **97 项参数目录**见[JSON](../../reports/2026-10-26-physics-effects-parameters.json)。每项保存数值、单位、证据类别、来源及适用限制；14 项仍为 null。JSON 是资料目录，不是会自动加载的运行配置。

## 2. 身体与运动

以下值来自固定提交的 [Prismarine Physics 源码](https://github.com/PrismarineJS/prismarine-physics/blob/4d573bc9bdf8e049a0bc9f9f93b56a68073f4950/index.js)；其为多版本兼容实现，不能等同 Hypixel 服务器代码。

| 参数 | 参考值 | 单位与证据 |
| --- | --- | --- |
| 玩家宽、深、高 | 0.6 × 0.6 × 1.8 | 方块；兼容参考，固定站立模型 |
| 普通地面直行速度 | 约 4.3171823142 | 方块/秒；兼容推导，约 0.2158591157 方块/tick |
| 普通地面疾跑速度 | 约 5.6123370085 | 方块/秒；直行的 1.3 倍，不含疾跑跳跃 |
| 潜行直行速度参考 | 约 1.2951546943 | 方块/秒；A 不启用蹲伏防坠 |
| 移动属性基础值 | 0.1 | 属性量，不是 0.1 方块/tick |
| 普通方块滑度 | 0.6 | 源码参考值 |
| 地面水平惯性系数 | 0.546 | 每 tick，0.6 × 0.91 |
| 空中水平惯性系数 | 0.91 | 每 tick |
| 重力 | 0.08 | 方块/tick² |
| 竖直阻力保留系数 | 名义 0.98 | 源码使用 float32 舍入，目录记录 0.9800000190734863 |
| 普通起跳速度 | 名义 0.42 | 方块/tick；目录保留源码 float32 值 0.41999998688697815 |
| 跳跃效果每逻辑等级增量 | 0.1 | 方块/tick/级 |
| 跳跃 V 起跳速度 | 约 0.92 | 方块/tick；由起跳基值加 0.5，A 禁用 |
| 跳跃 II 起跳速度 | 约 0.62 | 方块/tick；由基值加 0.2 |
| 空中加速度参考 | 0.02；疾跑 0.026 | 方块/tick²；不自动取代平台主动运动模型 |
| 自动台阶高度参考 | 0.6 | 方块；A 禁用 |

地面速度的计算保留为明确推导。令 f = 0.6 × 0.91，则 a = 0.1 × 0.1627714 / f³；直行稳定速度为 0.98 × a / (1 − f) 方块/tick，再乘平台 20 tick/秒得到表中值。**平台直接采用这个稳定速度作为即时主动速度，未导入参考实现的主动惯性过程。** 斜向速度仍按已接受的归一化输入处理，不把参考实现的斜移细节一并复制。

B 的自由飞行参考次序为先用当前竖直速度移动，再令下一速度等于 (当前速度 − 0.08) × 竖直阻力。该式仅描述无接触的参考递推；落地/撞顶仍按已接受的受阻速度清零规则处理。运动过程中采用扫掠碰撞，不把原实现的离散轴处理算法当作本项目已选求解器。

普通生命上限参考为 **20 HP**，来自 [Cuberite 玩家定义](https://github.com/cuberite/cuberite/blob/7fd3fa5c9345a3f1b949c0988c4849db00a68486/src/Entities/Player.cpp)；它对应 10 颗显示心，不是 20 颗心。该值仍是兼容参考，没有取得 Hypixel 完整服务端配置。

Heal Pool 的半径、周期和多来源组合仍待核验，不能把自然回血 80 tick 或再生 I 50 tick直接写成其正式参数。吸收刷新/重补及多个来源切换也未由数值目录自动决定。

## 5. 拆块效果与材料

挖掘公式依据固定版本的 [Prismarine Block](https://github.com/PrismarineJS/prismarine-block/blob/8c8d4e02ecffb2e9d47d07575687520ffef30852/index.js)，材料数据依据 [Java 1.8 blocks](https://github.com/PrismarineJS/minecraft-data/blob/5e063fa99cfe8ded065ec6788b66696b7e4ef143/data/pc/1.8/blocks.json)与[materials](https://github.com/PrismarineJS/minecraft-data/blob/5e063fa99cfe8ded065ec6788b66696b7e4ef143/data/pc/1.8/materials.json)。它们是兼容参考，不是 Hypixel 实测拆块表。

| 项目 | 参考值 |
| --- | --- |
| 急迫 I / II 的挖掘速度倍率 | 1.2 / 1.4 |
| 疲劳 I / II / III / IV及以上倍率 | 0.3 / 0.09 / 0.0027 / 0.00081 |
| 效率附魔加速项 | 等级平方 + 1，仅在工具基础加速满足条件时加入 |
| 可采集/不可采集的进度分母 | 30 / 100 |
| 离地减速分母 | 5 |
| 水下无水下速掘减速分母 | 5；A 不启用水体 |
| 羊毛 / 玻璃 / 木板硬度 | 0.8 / 0.3 / 2 |
| 末地石 / 染色陶瓦 / 黑曜石硬度 | 3 / 1.25 / 50 |
| 对应材质的木/石/铁/钻石/金工具倍率 | 2 / 4 / 6 / 8 / 12 |
| 所读 1.8 数据的剪刀对羊毛倍率 | 4.8；不擅自换成通用 15 倍假设 |

先计算工具及效率修饰，再应用急迫、疲劳和水下/离地修饰，每 tick 的拆块进度为有效挖掘速度 / 硬度 / 对应分母。材料不可采集与不可破坏、瞬时可破坏等情况需专门处理；原实现返回 Infinity 不表示本项目允许在世界状态存无穷值。实际进度随 tick 条件变化累计，不能把开工时长缓存后忽略药效变化。

例如按该兼容参考，地面无加成空手羊毛为 24 tick，木镐末地石为 45 tick，未附魔钻石镐黑曜石为 188 tick；这些是公式检查样例，不是 Hypixel 线上实测时间。防爆玻璃、床与地图保护等自定义语义继续按各自规则，不能由原版玻璃的硬度或爆炸抗性推断。
