## 3. 身体、移动、击退

| 参数 | 采用值/语义 |
| --- | --- |
| 玩家宽/深/高 | 0.6 / 0.6 / 1.8 方块；平面 AABB 固定，不随朝向旋转 |
| 主动速度 | 4 方块/秒 = 0.2 方块/tick；只有一个运动档位，无疾跑/潜行 |
| 输入 | 世界坐标二维方向，非零归一化，零停止；不允许斜向额外加速 |
| 普通近战水平冲量 | 每次有效伤害增加 0.30 方块/tick 的击退速度；无竖直冲量 |
| 击退方向 | 攻击者中心指向受击者中心；完全重合则使用攻击者当前朝向 |
| 叠加上限 | 水平击退向量合成后模长最多 0.60 方块/tick |
| 反向/侧向控制 | 沿用 P07，alpha=0.2、beta=0.5 |
| 衰减 | 每次 30 阶段先用当前击退与主动速度做扫掠运动，再将碰撞后剩余击退乘 0.75 |
| 恢复控制阈值 | 衰减后击退模长 <0.005 方块/tick 则清零；否则下 tick 继续 P07 受限控制 |
| 施加时序 | 60 阶段伤害产生的冲量在下一 30 阶段开始位移；不追溯本 tick 运动 |
| 接触距离/时刻容差 | 分别 1e−8 方块、1e−8 tick 内时间单位 |
| 数值速度零容差 | 1e−6 方块/tick；与上面的恢复控制阈值分开 |
| 碰撞迭代上限 | 8 次/tick；沿用 P05 超限保守停止并记诊断 |
| 虚空 | 沿路径首次失去正面积承载即请求本 tick 死亡；不能高速跨空隙；失去承载后本 tick 后续拆建/交战不能救回或产生攻击 |

承载、贴面滑动、无玩家身体阻挡、禁穿透继续按 P01–P10。玩家拆掉承载方块后需要重查：如果新状态仍有其他支撑则不死亡，否则按 A 规则结算。无承载判死不能用“身体中心还在岛上”替代。

## 5. 拆建、返还与遮挡

| 参数 | 采用值/语义 |
| --- | --- |
| 操作距离 | 玩家中心至目标格平面中心 ≤3 方块，含边界 |
| 操作朝向 | 当前朝向与目标中心方向夹角 ≤60°；中心重合时视为通过朝向条件 |
| 遮挡 | 玩家中心到目标中心的线段，排除目标自身，若进入其他墙/床碰撞体内部则拒绝；仅贴边不遮挡，承载桥面不遮挡 |
| 新桥面支撑 | 同承载层至少有一个四邻接格存在有效地面，不以仅对角邻接作为支撑 |
| 新墙支撑 | 正下方承载格存在；不要求旁边另有墙，不允许悬空墙 |
| 放置耗时 | 4 tick（0.2 秒），20 阶段启动，45 阶段最早在 started_at+4 完成；各阶段按既有规则复核，中断不扣物 |
| 拆羊毛耗时 | 固定 20 tick（1 秒），正确/错误工具均相同；正确工具只影响返还，未擅自增加工具速度体系 |
| 破床耗时 | 固定 40 tick（2 秒），无材料返还；只能破敌床 |
| 拆除完成阶段 | 50 阶段，在 started_at+duration 或以后合法完成；多人/重建实例冲突按 W06 |
| 对应关系 | 剪刀 ↔ 羊毛；原始不可拆岛屿和床不进入材料回收表 |
| 返还数量 | 每个合法拆除的玩家放置羊毛方块返还 1 个羊毛；双方放置的羊毛都可回收，不因放置者不同改变 |
| 工具判定 | 拆除期间须持续持有同一类工具；切手中断旧动作/进度。完成时再次校验剪刀，错误工具可拆但不返还 |
| 返还去向 | **优先进入拆除者背包**；放不下则在拆除者当前安全位置生成羊毛掉落物。位置无有效承载则溢出销毁并记原因，不回退到旧位置 |
| 返还原子性 | 同次提交方块移除、背包增量/掉落/销毁及 ID；同一方块实例最多产出一次，拒绝/重复完成不产出 |
| 拆掉墙下桥面 | **桥面上有墙时拒绝拆桥面，先拆墙**；这是已采用实验细则 |
| 自拆脚下桥面 | 允许，按移除后的承载重新判断并可能虚空死亡；返还不构成存活保证，随后死亡仍清除携带羊毛 |

返还与容量处理已随整表采用，包括直接入包、安全溢出掉落及无安全位置时的销毁；它们属于本档案实验规则。满容量不吞掉已成功回收的事件记录：数量分别记入接收、掉落、销毁，不能凭空复制。

| 友伤 | 关闭，队友不接受伤害/击退 |
