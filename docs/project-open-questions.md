## 六、需要与 Hypixel 分开核验的事实

- [Q01–Q15](rules/hypixel-bedwars.md) 和 [R01–R08](physics-effects-confirmation.md) 是取证清单，不会因为采纳平台规则而自动关闭。优先核验首版启用的模式、经济、近战/击退、复活保护、拆块和观察规则。
- Q15 团队陷阱共享冷却仍未知；现有 TeamState 仅允许明确指定实验或核验值后触发。牛奶、揭隐、多个来源效果和掉落分享等也有未核实边界。
- Game End 的历史证据仅确认 2025 年存活队员数优先于破床数；平台采用的等待复活计数、完整比较与并列平局仍需验证。社区赛程与 45 分钟第二批龙的推导也不是所有模式现服认证。
- 补证应记录模式、地图、补丁/日期、实验步骤和可复查结果；无法取证的值可作为具名实验输入，不得被写成 Hypixel 已核实事实。

## 建议讨论顺序

1. **先确定首个可训练里程碑和阵容**（OPEN-01、02），由此筛选真正需要立即讨论的玩法。
2. **确定首张 A 地图与必要物品/经济配置**（OPEN-04–07），形成可加载场景。
3. **补齐首版战斗、死亡和效果细则**（OPEN-08–12），逐项区分资料、平台实验值和已实现行为。
4. **定义观测/动作与训练采样契约**（OPEN-13–17），再选模型算法及训练器。
5. **根据已确认范围落实类型、处理器、测试和回放**（OPEN-18–21）；界面、远程接入按需要扩展。

该顺序是本次整理的建议，并未由用户采用为正式开发排期。已采用的核心规则、训练奖励和时序不在此重开。
