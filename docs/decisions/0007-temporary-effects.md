# 0007：本生命临时效果与死亡清理

## 已确定

用户选择本生命临时效果随死亡统一清空，包括药水、陷阱产生的此类状态。上一条生命的效果及其后续作用不延续到复活后的新生命。

已确定保留的团队升级仍在 `TeamState` 中，不因个人临时效果清理而重置；复活后按队伍状态重新计算其作用。本规则不清空队伍的升级或陷阱队列，也不定义所有队伍区域效果的精确生效条件。

普通生命与吸收生命沿用 [0006](0006-vitality-and-absorption.md)；复活时普通生命回满、吸收清零。吸收剩余量只在生命状态保存一份，来源、时长与临时效果如何关联继续待设计。

## 同种药水再次饮用

用户接受新效果覆盖旧效果，不累加持续时间：

- 等级使用新药水的等级。
- 到期时刻设为施加时的仿真时刻加新药水的持续时间。
- 旧效果的剩余时间不加入新时长；旧同种药水记录被替换，不因新药水到期而恢复。

```text
到期时刻 = 当前仿真时刻 + 新药水持续时间
```

该规则针对重复饮用同种药水；不同来源的等级型增益按下节处理，不能据同种药水覆盖规则删除其他来源的同类效果。特殊效果的来源合并继续待定。

周期型效果符合下文同等级、同周期条件时，刷新保留下一次触发时刻；其他情况继续待定。被替换的旧效果不能通过独立待处理事件重复施加作用。吸收量重补、瞬时治疗等需要额外过程的效果，其具体状态更新也继续单独设计，不由等级与时长覆盖自动确定。

## 不同来源的等级型增益

用户接受对速度、急迫这类等级型增益采用以下规则：

- 各来源分别保留记录、分别计时。
- 同时只取最高等级生效，不叠加强度；同等级也不因来源数量而加倍。
- 较弱效果被压制期间，时间照常流逝，不暂停计时。
- 强效果结束后，若弱效果尚未到期，则恢复弱效果；已到期的记录不恢复。

因此需要保存被压制但尚未到期的来源记录，当前生效等级由有效记录派生，不另存一份独立真值。同一种药水的旧记录已被覆盖时，不属于可以恢复的其他来源记录。

团队升级仍从 `TeamState` 读取，不为临时效果清理而复制或重置永久升级数据。具体来源键、效果实例标识格式及查询结构继续待设计。

本节只确定等级型增益的合并，不自动规定吸收生命、周期回血、持续伤害等特殊效果的状态与触发方式。

## 周期效果首次施加

用户选择周期型效果首次施加后，等待一个完整周期再首次触发，不立即额外触发一次：

```text
首次 next_trigger_at = 施加时的仿真时刻 + 该效果触发周期
```

之后按周期调度；具体周期和作用量仍由规则配置确定，不设默认数值。瞬时治疗等非周期效果不自动套用等待一个周期的规则。

## 周期效果刷新

用户选择在等级和触发周期均不变时，刷新效果接续原触发节奏：

- 新效果记录承接原来的下一次触发仿真时刻，不重新等待一个完整周期。
- 到期时刻仍按该效果的刷新规则重算；同种药水按施加时刻加新持续时间计算。
- 旧记录仍被替换，实际触发由新记录承担，不保留两个独立触发来源，也不因刷新额外立即触发一次。

因此到期时刻和下一次触发时刻是两项不同的状态，不能仅由刷新后的剩余持续时间反推触发进度，分别使用已确定的 `expires_at` 和 `next_trigger_at` 字段。正式类型与协议尚未确定。

等级变化、触发周期变化、多个来源的周期效果共同作用，以及刷新/触发/到期在同一时刻发生时的顺序继续待设计。同等级、同周期的接续规则不自动推广到这些情况。

## 基础 EffectState（字段已确定，待实现）

用户已确定按实例保存以下六个基础字段。字段名和基本职责已接受；具体数值类型、来源结构、标识格式、可选值编码及版本化协议仍待细化，没有相应运行实现。

| 字段 | 用途 |
| --- | --- |
| `effect_id` | 唯一区分实例，识别待处理事件是否仍有效 |
| `effect_type` | 效果种类 |
| `source` | 来源及覆盖分组依据 |
| `level` | 适用于等级型效果的等级 |
| `expires_at` | 到期仿真时刻 |
| `next_trigger_at` | 周期型效果的下次触发时刻，非周期型不需要 |

周期和作用强度等规则参数由效果定义提供；特定效果若需要其他可变过程状态，后续单独设计。

剩余时间可由到期时刻与当前仿真时间派生，无需维护另一份独立倒计时。完整快照需保存恢复效果所需的时间与过程状态；只保存到期时刻不足以恢复周期型效果的触发进度。

死亡清理后，旧效果不能继续通过待处理事件施加作用。后续用户已在 [0010](0010-player-lifecycle-branches.md) 确定 `life_index`：本生命效果事件执行前校验玩家仍存活且生命序号匹配，同时检查效果实例仍有效。具体事件取消、队列清理与调度实现继续待设计。

## 后续验收

以下是实现时需要增加的验证，不是已经通过的测试：

- 本生命临时效果在死亡后不再影响玩家，也不因复活而恢复。
- 周期型效果的旧待处理事件不会作用到下一条生命。
- 周期型效果首次施加后等待完整周期，不额外立即触发；非周期型效果不误用此规则。
- 同种药水再次饮用后使用新等级与新到期时刻，时长不叠加，旧药水记录不恢复；同等级、同周期刷新时，下一次触发时刻保持不变且不重复触发。
- 不同来源的等级型增益取最高等级，不因同等级来源增加而加倍；强效果结束后只恢复仍未到期的弱效果，被压制期间不暂停计时。
- 团队升级及其本局数据不被个人效果清理重置。
- 保存/恢复效果时间与必要进度后，后续作用保持一致。
