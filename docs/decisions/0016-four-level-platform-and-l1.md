# 0016：四层平台与 L1 范围

日期：2026-10-27。状态：**用户已确认四层目标与下列 L1 范围；完整 L1 尚未实现。数值与新增配套细则随后已随参数 v0.1 整表采用，尚未实现完整 L1。**

## 1. 用户确认与适用范围

用户提出四个复杂层级：L1 二维必要元素，L2 二维增加复杂内容，L3 三维简化版，L4 对 Hypixel 的仿真模拟。共同基础设施、多档案组织以及 L3 从精简玩法扩展的安排仍是架构建议，不把 L2–L4 的详细范围视为已经冻结。

后续用户选择 L1 单资源、少量商品、首个验收直接 2v2，采用基地与中央资源点。对 L1-01–22 清单的最新回复为：“L1-05 使用对用的工具拆除材料会返回材料；L1-19 先提出完整实验参数表；其他采用”。这里按语义理解“对应的工具”，不修改原始引文。

随后用户回复“采用，并给出L1的完整的实现规划”，整张实验参数 v0.1 与新增配套细则也已采用：免费剪刀回收羊毛、返还优先入包及安全溢出、保护解除、地图与各项数值均按该表执行。本轮要求编制规划，未启动整个引擎实现。

## 3. 与已有设计的关系

- 0003 和 P01–P10 的连续平面移动、碰撞/承载、非身体阻挡、固定高度及虚空简化继续适用；不是退回离散格子移动。
- 0004–0010 的背包、生命绑定、动作中断、生命转换与统计继续适用；四种资源通用代码在本档案只启用一种，不能复制团队钱包。
- 0013–0015 的世界所有权、固定阶段、请求/队列去重、死亡批次、快照与故障处理继续适用；关闭机制不等于删除既有设计。
- 普通资源拾取沿用 32 阶段、固定 player_order 和 (created_at, entity_id) 顺序；关闭分享不改变竞争规则。
- L1 的单资源、简化护甲/地图/赛程等是平台实验档案。参考 BW-GAME-01、BW-WORLD-01–03、BW-LIFE-01–06、BW-COMBAT-01、BW-ECON-01–05、BW-SHOP-01、BW-ITEM-01 和 BW-END-01–02 进行机制追踪，不宣称这些简化/数值是 Hypixel 行为。
