# 开发阶段

更新：2026-10-25。以下后续阶段是工程推进建议，未设定日期或性能承诺。

## M0：工程初始化（当前）

- Python 包布局、工程信息 CLI、开发安装及构建配置。
- 引擎、接口、策略、运行器、回放和前端目录。
- 架构、契约问题清单、开发指南和决策记录。
- 本地工程检查、GitHub CI、公开仓库。

M0 不包含游戏玩法、Agent 对局、网络服务或回放界面。

## M1：最小规则与本地闭环（待设计）

先确定空间、规则、观测、动作和时间语义，再实现可用两个简单策略运行的无界面对局。验收应覆盖床/复活/淘汰与终局、非法动作、同动作序列的复现、隐藏信息边界。具体规则范围仍待确定。

## M2：策略接入与实验（建议）

在本地契约稳定后选择标准环境适配或进程/网络协议；增加超时与异常行为、批量配置、种子集合和结果导出。先做正确性验证，再制定与测量吞吐量指标。

## M3：完整记录与回放（建议）

固定记录格式、版本与状态检查方法，再实现网页展示和时间轴。回放应能核对玩家、床、资源及可建造地形，而不只记录玩家位置。
