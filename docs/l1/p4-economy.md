# L1 P4：资源、购物、拆建与回收

P4 按 [L1 实验参数](../rules/l1-experiment-parameters-v0.1.md)接入资源与地形处理器。固定 tick 阶段为：0 物品到期、25 生成、32 拾取、40 购买、45 放置与丢资源、50 拆除与玩家破床。每笔竞争读取此前已提交状态；背包、地面数量、方块实例、ID、任务和事实一起校验提交。

- 三个生成器按各自计时检查同类地面资源的半开积累区域，满额仍按周期续期，不积攒欠产；同 tick 新资源可以在 32 拾取并用于 40 购买。普通拾取按固定玩家顺序、再按实体创建时刻和 ID 处理，按剩余堆叠容量部分接收；分享关闭。
- 购买按实际位置、资金和扣款/发货后的总容量复核；失败不扣款。升级剑替换木剑，原手持被移除时清空，不自动切手。主动丢铁在 45 生成地面物品，按单实体上限拆分并记录拾取延迟；不重复执行旧请求。
- 羊毛桥面与墙体按耗时完成；保护区、目标、支撑、身体/地面物品重叠、距离、朝向和遮挡在开始与完成时检查。同格竞争首笔合法成功，其余不扣物。每个方块有新实例 ID，旧拆除目标不能作用于重建方块。
- 用剪刀拆羊毛每格返还 1 个：优先入包，溢出在安全位置掉落，否则销毁；错误工具能拆但不返还。墙下桥面须先清墙。移除承载后的玩家即时产生待死亡结算候选，失去承载的地面物品移除。床不产生材料，玩家破床在 50 阶段计入所属队伍。
- 训练预置可以指定初始地面物品及其可拾取时刻；构造器负责拆分、源标识、实例 ID 和到期任务。快照绑定 `l1-p4-1` 引擎版本；不静默加载 P3 快照。

验证覆盖资源满额续期、同 tick 拾取后购物、满包购物与部分拾取、固定顺位竞争、丢弃延迟和不重复、同格争抢、旧实例、正确/错误工具、满包回收溢出、墙下桥、脚下承载移除、玩家破床，以及到期先于拾取。[P5](p5-combat.md) 已接入战斗、死亡/复活与对局结果；完整 Runner 与脚本对局仍待 P6。

这些数值和顺序属于已采用的平台实验。BW-ECON-03 的生成参数、BW-WORLD-02 的地图/建造细节及 BW-LIFE-06 的保护参数仍不构成 Hypixel 现服实测。
