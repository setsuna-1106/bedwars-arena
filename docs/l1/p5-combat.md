# L1 P5：战斗、生命与终局

P5 实现 [L1 实验档案](../rules/l1-experiment-parameters-v0.1.md)的近战、死亡批次、复活、全局毁床和 Game End。所有数值是平台实验，不视为 BW-COMBAT-01、BW-LIFE-04/06 或 Hypixel 现服内部时序的实测。

- 60 阶段先冻结合格攻击，按固定玩家顺序处理出手、保护、受击间隔、减伤、击退和有效伤害归因，最后统一转换死亡生命。同阶段致死不撤销已合格攻击，可以互杀；虚空已失效的生命不能继续攻击或被当作合格目标。
- 死亡前固定本批各死者携带铁及归属。存活击杀者按容量接收，安全位置溢出掉落；击杀者同批死亡或已等待/淘汰时该来源资源销毁。无击杀者在安全死亡位置掉落，否则销毁；每个来源分别校验接收＋掉落＋销毁等于原数量。非资源装备按生命结束清除。
- 死亡时床仍在则固定本次复活资格，60 tick 后新建生命；等待期间床被毁不撤销资格。新生命递增 `life_index`，恢复基础装备和出生保护，保留防具与统计，清除旧动作、冷却、击退和归因。同 tick 的 50 破床先于 60 死亡。
- 70 阶段从成员生命派生队伍淘汰；90 阶段先按仍参赛队伍数判断自然胜负。定时全局毁床不计玩家归属；Game End 依次比较存活＋等待复活人数和有归属的敌方破床数，最高并列为平局。结果固定后拒绝继续推进。外部 episode 时限和奖励由 P6 Runner 处理。
- 世界快照绑定 `l1-p5-1` 引擎版本，恢复校验队伍、生命、复活任务和结果；不静默加载 P4 快照。

测试覆盖保护、受击/攻击冷却、同阶段互杀、资源守恒和容量溢出、跨生命归属、无归属虚空、等待中失床后复活、同 tick 破床后最终死亡、双方全员等待/全灭、终局唯一性与 Game End 比较。完整 Runner、策略对局、外部截断和奖励仍待 P6。
