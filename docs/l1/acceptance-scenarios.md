# L1 分阶段验收场景

2026-10-27。下列场景把[实现规划验收矩阵](../l1-implementation-plan.md)具体化。CFG（P0）、TX（P1）、PHY（P2）和 ACT 的 P3 接入边界、ECO/BUILD 的 P4 场景与 COMBAT/LIFE/END 的 P5 世界场景已有对应行为测试；Runner 的 k>1 与外部截断已按 P6 测试，P7 的重放边界及四个受控样本已核对，P8 的受控 2v2 采样、更新与恢复已验证；其余为待后续实现和执行的测试设计，不是已通过的玩法测试。除非特别说明，采用内置 profile/map、20 Hz、固定 player_order `red_1, red_2, blue_1, blue_2`；时间、价格和物品数值取已采用档案，不另抄一份默认规则。涉及中局的状态用合法训练预置或先运行输入序列构造，不直接改引擎内部队列。

| 组 / 阶段 | 固定场景和操作 | 必须断言的结果 |
| --- | --- | --- |
| CFG / P0 | 加载三份内置定义；分别删掉预算字段、写 NaN、启用 traps、改图层/出生支持、引用不存在的队伍、改预期哈希 | 有效定义通过；每个无效输入被拒绝，返回独立副本，三个内容哈希可复核；不创建对局 |
| TX / P1 | 建立 tick 边界快照；一次计划同时改变玩家、排队、ID 与事实，并在最终校验处注入失败；另走过没有任务的空阶段 | 故障批次无任何部分提交、不发布半 tick；空阶段游标前进；旧生命/实例任务正常跳过、去重与游标恢复一致 |
| PHY / P2 | 在边缘与墙角以 0.2 方块/tick 直走、斜走、贴墙滑动；使用独立小几何夹具配置宽 1 格的空隙，移动加有效击退使起终点各有地面而路径中段失去全部承载 | 对角归一化与直走等速，不能穿墙，表面接触和贴边滑动成立；沿路径首次失载生成死亡候选，不能跨过空隙；玩家不互相阻挡 |
| ACT / P3 | 从同一边界向 `red_1` 发两个不同 ID 的移动更新、一个合法转向和一次购买；封口后发送新旧请求，复活后重发旧生命请求；重复一条已记录请求 | 移动组全部拒绝、原动作保持，其他组独立处理；迟到/旧生命拒绝；同内容重试不重复执行、异内容拒绝；四席位观测互不共享可变对象 |

| BUILD / P4 | 在左岛外邻接放置桥面 `(-16, 0)`，持木剑拆一次；另一实例持剪刀拆一次。再让拆除者拥有 384 铁、木剑和剪刀（8 等效堆叠），在安全位置回收；对同格重建和桥面上有墙分别尝试旧完成请求/拆桥 | 错工具无返还；剪刀每个实例恰返 1 羊毛；满包回收从安全位置生成 1 羊毛，不复制；旧实例完成不能作用新实例，有墙先拒绝拆桥 |

| LEARN / P8 | 至少两个完整 2v2 episode 采样，按选定算法实际更新一次、冻结评估、保存检查点、在新进程恢复再更新 | 模型、优化器、计数及必要 RNG/采样状态正确恢复；reset 世界不重建学习状态；冻结评估权重不变，淘汰席位仍获得最终团队奖励 |

## 40 局固定运行清单

P6 已完成 G1，P9 再执行以下矩阵。固定 seed 为 `101–110`；每个 seed 运行四种席位配置。`E1/E2` 是经济进攻策略的两个独立会话，`D1/D2` 是护床反击策略的两个独立会话，数字表示会话身份，不暗示不同算法。`red`、`blue` 内的顺序对应场景的两个固定席位，顺序不会轮换世界 player_order。

| 配置 | red 的两个席位 | blue 的两个席位 |
| --- | --- | --- |
| A | E1、E2 | D1、D2 |
| B | E2、E1 | D2、D1 |
| C | D1、D2 | E1、E2 |
| D | D2、D1 | E2、E1 |

P7 已按以下四种预选席位使用不对称受控预置执行 `101-A`、`102-B`、`103-C`、`104-D`；首局自然结束，后三局在 tick 650 截断，均从 tick 200/400 恢复验证。它们不是 P9 的 40 局标准矩阵。每局记录 seed、四席策略和版本、实际输入、备用动作、结果/截断/故障以及 profile/map/scenario 哈希；若因策略确定性而产生完全相同的输入和结果，不把重复记录当作独立随机证据。重放样本预选 `101-A`、`102-B`、`103-C`、`104-D`；早/中边界在实际运行记录中选择并记录 tick，若它们未覆盖上表的特殊状态，另用受控场景补齐，不能声称随机局已经覆盖。至少一个受控场景实际发生购买、搭桥、破床和淘汰，不能只靠等待 Game End。
