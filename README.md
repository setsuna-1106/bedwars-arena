# BedWars Arena

二维 BedWars 多智能体仿真平台，用于外部策略接入与可重复实验。

现实规则参照已确定为 **Hypixel 的 Minecraft Bed Wars**。后续设计与实现查阅[Hypixel 规则参考](docs/rules/hypixel-bedwars.md)，证据与检索过程见[规则调研](reports/2026-10-25-hypixel-bedwars-rules.md)。具体模式、地图、规则版本及二维化简化仍待确定；第三方 BedWars 项目用于工程参考，其玩法不能直接作为本项目规则标准。

**当前阶段：core 基础模块（0.1.0.dev0）。** 已提供 TeamState 类型/JSON 编码、团队交易与状态转换、参考规则档案、确定性事件排序及行为测试。完整世界引擎、玩家物理/效果应用、Agent 对局、远程 API 和回放界面尚未实现，不能启动完整对局。

## 快速开始

需要 Python 3.11+。

```bash
git clone https://github.com/setsuna-1106/bedwars-arena.git
cd bedwars-arena
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
bedwars-arena info
python scripts/check.py
```

`bedwars-arena --help` 查看入口，`bedwars-arena info --json` 输出实现状态。当前 CLI 不启动游戏；已实现的内部调用见 [core 类型与排序契约](docs/decisions/0012-team-core-types-and-ordering.md)。

## 核心目标

构建一个基于 Minecraft BedWars（起床战争）游戏机制的二维模拟对战平台，通过标准化 API 向外部决策算法提供游戏环境信息，接收算法生成的行动指令，并由模拟引擎执行和更新游戏状态。

平台旨在为智能体决策算法开发、多智能体博弈、策略优化及自动化实验提供一个可控、可扩展、可重复的测试环境。

用户已明确平台还需用于决策模型训练，支持跨局持续学习；每局世界初始化与模型、优化器等学习状态的初始化分开。每局策略绑定固定模型版本、训练器可跨局更新，基础结果奖励和检查点方向已确定；训练算法、完整接口与实现仍待落实，目前尚无训练实现。

## 基本交互闭环

```text
模拟引擎生成游戏状态
        ↓
API 向各智能体提供环境信息
        ↓
外部决策算法生成行动指令
        ↓
API 接收行动指令
        ↓
模拟引擎校验并执行行动，更新游戏状态
        ↓
下一次交互，直至对局结束
```

外部算法负责决策，模拟引擎负责规则执行和状态更新。具体可见信息、行动语义和推进时序需要在 API 契约中明确。

## 模块职责（目录已预留，行为待实现）

| 部分 | 建议职责 |
| --- | --- |
| 模拟引擎 | 管理地图、玩家、队伍及规则，执行行动并判定对局结果。 |
| 智能体接口 | 定义观测、行动、对局生命周期和错误反馈；为外部算法提供一致的接入方式。 |
| 实验运行器 | 配置对局、运行批量实验，记录结果及复现所需信息。 |
| 可视化与回放 | 展示引擎输出，帮助检查行动、状态变化和对局过程。 |

围绕“可控、可扩展、可重复”，后续可将规则与地图配置、随机种子与版本记录、无界面批量运行、策略替换能力作为验收项。具体指标待制定。

## 首轮设计需要明确的问题

- **空间细节**：三维方块网格、玩家连续移动与轴对齐矩形平面碰撞体已定；正式平面加高度、前期纯平面实验已接受。坐标轴、方块单位、脚底高度参考点与路径碰撞/贴面滑动已定；身体尺寸、碰撞求解细节，以及搭桥和坠落的具体表达方式待确定。
- **规则范围**：首版需要实现的队伍规模、床与复活、资源、商店、战斗、建造和胜负条件。
- **观测边界**：智能体能获得的信息、视野规则及隐藏信息的处理。
- **行动与时间**：动作粒度、执行耗时、多智能体动作的收集与结算顺序。
- **接入契约**：首版采用 Python 进程内调用；具体方法签名、策略生命周期及异常和非法动作的处理待确定，未来进程/网络协议另行选择。
- **复现标准**：首期采用 binary64，固定程序版本/运行环境下重放一致、浮点快照往返恢复已定；配置、随机性、算法版本和行动记录的完整保存格式仍待确定。

接入方式、模块边界、上述空间表示和玩家生命周期分支等已有设计决策；其余具体方案与实现边界详见[接口与时序草案](docs/contracts.md)。
