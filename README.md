# BedWars Arena

二维 BedWars 多智能体仿真平台，用于外部策略接入与可重复实验。

**当前阶段：工程骨架（0.1.0.dev0）。** 已提供 Python 包、项目信息 CLI、模块目录、开发文档及 CI；模拟引擎、游戏规则、Agent 对局、远程 API 和回放界面尚未实现。

## 快速开始

需要 Python 3.11+。

```bash
git clone https://github.com/setsuna-1106/bedwars-arena.git
cd bedwars-arena
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
bedwars-arena info
python scripts/check.py
```

`bedwars-arena --help` 查看入口，`bedwars-arena info --json` 输出工程状态。当前命令用于检查工程安装，不启动游戏。

## 核心目标

构建一个基于 Minecraft BedWars（起床战争）游戏机制的二维模拟对战平台，通过标准化 API 向外部决策算法提供游戏环境信息，接收算法生成的行动指令，并由模拟引擎执行和更新游戏状态。

平台旨在为智能体决策算法开发、多智能体博弈、策略优化及自动化实验提供一个可控、可扩展、可重复的测试环境。

## 基本交互闭环

```text
模拟引擎生成游戏状态
        ↓
API 向各智能体提供环境信息
        ↓
外部决策算法生成行动指令
        ↓
API 接收行动指令
        ↓
模拟引擎校验并执行行动，更新游戏状态
        ↓
下一次交互，直至对局结束
```

外部算法负责决策，模拟引擎负责规则执行和状态更新。具体可见信息、行动语义和推进时序需要在 API 契约中明确。

## 模块职责（目录已预留，行为待实现）

| 部分 | 建议职责 |
| --- | --- |
| 模拟引擎 | 管理地图、玩家、队伍及规则，执行行动并判定对局结果。 |
| 智能体接口 | 定义观测、行动、对局生命周期和错误反馈；为外部算法提供一致的接入方式。 |
| 实验运行器 | 配置对局、运行批量实验，记录结果及复现所需信息。 |
| 可视化与回放 | 展示引擎输出，帮助检查行动、状态变化和对局过程。 |

围绕“可控、可扩展、可重复”，后续可将规则与地图配置、随机种子与版本记录、无界面批量运行、策略替换能力作为验收项。具体指标待制定。

## 首轮设计需要明确的问题

- **二维表示**：俯视网格、连续平面或其他形式，以及高度、搭桥和坠落的表达方式。
- **规则范围**：首版需要实现的队伍规模、床与复活、资源、商店、战斗、建造和胜负条件。
- **观测边界**：智能体能获得的信息、视野规则及隐藏信息的处理。
- **行动与时间**：动作粒度、执行耗时、多智能体动作的收集与结算顺序。
- **接入方式**：本地调用、独立进程或网络协议，以及超时和非法动作的处理。
- **复现标准**：配置、随机性、算法版本和行动记录需要保存到什么程度。

上述问题是设计讨论入口，目前没有确定具体实现方案；详见[接口与时序草案](docs/contracts.md)。
