# 接入示例

[L1 受控对局预置](l1-controlled-2v2.json)用于验证购物、搭桥、破床和最终淘汰：红队预持铁和一档防具，蓝队初始 HP 降低，属于不对称功能测试。运行命令和标准对局入口见 [P6 Runner](../docs/l1/p6-runner.md)。

策略使用公开观测并返回请求列表，Runner 负责对局身份、轮次封口和逐 tick 推进。[P7 受控演示](l1-p7-showcase.py)生成可定位回收、失床后淘汰与碰撞的离线回放；[四样本重放脚本](l1-p7-four-matches.py)按计划检查不同席位和快照边界。独立进程接入和训练仍待后续工作。
