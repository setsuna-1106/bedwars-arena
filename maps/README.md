# 地图

L1 更新（2026-10-27）：固定三岛地图与实验参数 v0.1 已采用，见[参数表](../docs/rules/l1-experiment-parameters-v0.1.md)；P0 已将资产和加载器放入 Python 包；详见[P0 定义](../docs/l1/p0-definitions.md)。以下未定项为此前通用状态，L1 已确认的坐标/数值不再重选。

以下通用地图设计保留给 L2–L4；L1 固定三岛静态地图已实现加载校验。已选择方块网格、玩家连续移动与轴对齐矩形平面碰撞体，见[空间决策](../docs/decisions/0003-grid-terrain-continuous-players.md)；其余层级地图格式尚未确定；完整对局尚不可运行。

2026-10-26 用户已明确：只从几个固定地图中选择，不设计地图生成器。新局选择预置 map_id 并绑定版本/内容，seed 不生成地形；已采用先提供两张自制固定 A 实验地图（两队与四队）；具体 ID、坐标、资产、加载器与文件格式尚未确定。训练场景在选定固定地图上预置玩家、资源、床等状态，逻辑预置范围与默认值已采用，具体输入 Schema/子状态字段待定；对局内合法拆建仍更新可变地形。WorldState.generators 是资源生成器，继续按经济机制设计。创建/校验/恢复与训练预置见 [W03](../docs/decisions/0013-world-engine-and-state.md)。

后续地图应记录 ID/版本，并在格式中明确地形、出生位置、床、资源点和可建造区域。

网格格坐标 `(i, j, k)` 对应 `[i, i + 1) × [j, j + 1) × [k, k + 1)`；位置参考点所在格按各轴 floor 派生，负坐标也向下取整。玩家碰撞/占用查询覆盖完整身体，脚底所在格不直接等于承载方块。半开区间只确定格子归属，表面接触与穿透按碰撞规则判断；地图有效范围的具体值由各图配置，越界行为沿用已采用的 P01/P09。

正式地形已选择三维方块网格，每个方块由整数格坐标定位，支持多层桥梁、悬空结构和逐块拆建；按已采用的 [P/F/V](../docs/physics-effects-confirmation.md)，首期底层使用只存非空气格的稀疏字典，已加载且明确声明范围内缺键才为空气；原点/有效范围/建造限制/虚空高度分别由地图声明，具体地图值、文件格式与查询接口待定。前期 A 实验限制单一行走层、无上下重叠通路，先验证平面移动/碰撞/击退；正式 B 再加入竖直运动与多层通行。方块边长为 1，水平 `(x, z)` 为玩家矩形中心，向上为正的 `y` 为脚底高度。上述为已接受设计，尚无地图或物理实现。

已接受的[床关联方式](../docs/decisions/0011-team-state.md)将床定义为特殊地图对象，所属队伍、位置与占用区域由地图配置；存亡与摧毁时刻仅保存在 `TeamState.bed_state`。空间查询结合两者，不在地形或实体中重复维护另一份独立存亡状态；若覆盖多格，各格对应同一逻辑床。周围防御方块归普通可变地形。床的具体尺寸/占用格式、碰撞与通行行为仍待确定，尚未实现。

已接受的[陷阱基地范围归属](../docs/decisions/0011-team-state.md)由地图配置触发区域，床被摧毁后继续使用该范围，队列仍可触发且满足条件可追加购买。全队淘汰后保留队伍记录/队列但停止触发和购买；具体范围几何/边界与配置编码仍待确定，尚未实现。

标准初始化只为本局启用的非空参赛队创建 `TeamState`，校验玩家/队伍关联与床、出生配置、基地范围引用；地图预留但未启用的槽位不作为参赛队伍。首版单局阵容固定；具体地图格式与训练场景覆盖接口另定。

已接受的[出生规则](../docs/decisions/0010-player-lifecycle-branches.md)要求首版每张地图为每队配置一个固定出生点及初始朝向，同队成员开局与复活共用。地图还需划定覆盖完整出生矩形的禁建区域，对所有队伍禁止放置方块；出生承载地形不可被拆除或爆炸破坏。禁建与地形保护均归地图约束，不重复存入每个玩家，也不直接授予玩家伤害/击退免疫；具体范围、边界与配置格式仍待设计。多个出生点属于未来扩展，尚未采用选择机制。
