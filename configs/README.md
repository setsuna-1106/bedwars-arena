# 配置

物理/效果数值资料见[参数说明](../docs/rules/physics-effects-parameters.md)与[97 项目录](../reports/2026-10-26-physics-effects-parameters.json)。它们区分官方历史、兼容参考、候选与平台实验，并保留未知值；当前没有物理运行加载器，不能将资料文件当作自动生效的完整对局配置。

完整对局和批量实验配置仍待设计。已实现的[TeamRules 参考档案](../src/bedwars_arena/core/data/hypixel_team_reference_v1.json)随 Python 包分发，按模式显式加载；它不是完整可运行对局配置。

[W03 创建/恢复及训练预置范围/默认值](../docs/decisions/0013-world-engine-and-state.md)已采用。地图只需从预置固定集合选择 map_id 并固定版本/内容，不设计地图生成器或地形生成参数。训练预置与规则定义分别表达，允许预置阵容、空间、物品/进度/手持、生命/已支持效果、队伍床/升级/陷阱，以及待 W09 定义的资源/容器/生成计时。训练新局 tick=0，默认玩家存活、life_index=1、统计零、动作空；实例 ID/效果截止/关联事件由构造器生成，不直接配置内部队列。具体 Schema/子状态字段待定；完整场景校验已启用机制的必要参数和处理器，成功才发布，恢复不套新局默认值。

官方历史值与社区候选分开标注：完整升级价格默认禁用，显式 opt-in 后才用于研究参考；共享触发冷却未知，须明确覆盖并记录来源，不能默认零。接口、排序与限制见 [0012](../docs/decisions/0012-team-core-types-and-ordering.md)。

格式确定后应明确 schema/规则版本、地图、seed、策略标识与终止条件；不要把凭证或本机路径放入共享配置。
